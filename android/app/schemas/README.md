# Room schemas

The committed `1.json` through `5.json` files are the versioned Room migration baselines. KSP is configured to export the current schema here during Android builds; generated changes must match the reviewed baseline before commit. `RoomMigrationTest` covers the non-destructive path through v5, including preserved recording/draft/original rows, frozen remote versions, bounded upload rewinds, privacy state, and version-conflict backfill. A legacy conflict with incomplete or mismatched local identity becomes `UNREVIEWABLE` rather than adopting a version. Destructive fallback is intentionally disabled. The committed JSON is structurally checked locally; Room's generated identity and device migration validation still require the Android Gradle/instrumentation run.
